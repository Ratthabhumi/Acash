## 3. Epistemic Taxonomy & Classification Standard

Every concept, paper, heuristic, and candidate idea recorded in this library is tagged with an explicit epistemic status to preserve analytical integrity:

| Epistemic Tag | Definition | Permitted Usage |
|---|---|---|
| `ACADEMIC_REFERENCE` | Peer-reviewed mathematical or economic literature with formal theoretical or empirical grounding. | Theoretical foundation, baseline benchmarking, and risk modeling. |
| `ESTABLISHED_CONCEPT` | Standard industry quantitative finance methodology widely replicated in production systems. | Feature engineering, portfolio risk constraints, and execution cost modeling. |
| `RESEARCH_PRINCIPLE` | Practical quantitative heuristic or operational rule of thumb grounded in institutional experience. | Architectural guardrails, complexity budgeting, and humility checks. |
| `ARCHITECTURAL_CONCEPT` | Structural design for future data ingestion, pipeline staging, or engine coordination. | Blueprint for post-qualification pipeline development. |
| `CANDIDATE_RESEARCH_DIRECTION` | Promising research theme requiring formal hypothesis specification prior to investigation. | Intake queue for future hypothesis design sprints. |
| `UNVERIFIED_SOCIAL_MEDIA_CLAIM` | Heuristic, discretionary pattern, or claim sourced from trading communities/social platforms without rigorous statistical verification. | Candidate feature ideation only after mathematical decomposition and formal falsification testing. |
| `REQUIRES_EMPIRICAL_VALIDATION` | Unproven hypothesis or parameter set that must pass full in-sample, out-of-sample, and walk-forward testing. | Pending empirical verification under strict anti-p-hacking controls. |
| `FUTURE_RESEARCH_ONLY` | Long-term roadmap item deferred until baseline infrastructure (e.g., Gate G7 soak, Stage S11) is fully complete. | Quarantined from active engineering sprints. |
