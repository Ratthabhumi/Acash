## Proposed frozen study (owner review before execution)

- Initial broker capital USD 1,000; household THB conversion uses the existing
  historical convention. Illustrative savings, not the owner's actual finances.
- Fixed monthly THB: 1,000 / 3,000 / 5,000 / 10,000 on the same 119 full-window
  saving events as V35/V36; independently assert that event count before execution.
- Cadence IDs should encode event intervals explicitly: 1 / 3 / 6 / 12 events.
  Do not confuse V36's F2=quarterly/F3=annual labels with interval numbers.
- Primary: four savings amounts x four cadences x one fixed 60/40 benchmark =
  16 cells; plus four monthly fee/spread-free controls = 20 primary cells.
  Portfolio choice/grid is proposed, not silently ratified or optimized after results.
- Base scenario: THB 400 sender fee, hypothetical 0.5% spread, USD 0 intermediary,
  zero-session delay. Preselect isolated sensitivities on THB 3,000 / quarterly:
  sender 250/550; intermediary USD 15; delays 1/3 sessions; whole-share versus
  fractional constraint; R2 versus R2F interpretation. No unrestricted product grid.
- Freeze explicit BIL unresolved cash-in-lieu handling if any sensitivity introduces
  BIL; never fabricate its price. Bank-route/fractional eligibility stays UNVERIFIED.
- Report saved/remitted THB, each friction, broker NAV, terminal external cash,
  transit, household THB wealth/XIRR, broker TWR, cash exposure and trade counts.
  Different contributions are not compared by terminal wealth alone. A single
  historical path cannot select an optimal future cadence.

## Validation and acceptance

- Fail-first/adversarial tests: varying FX with exact THB savings; duplicate,
  permuted/nonmonotonic dates; non-finite/negative money; year boundaries and
  session mapping; missing/stale FX; insufficient fees and cent-rounding boundary;
  minimum remittance; no negative cash, double fees or duplicate contributions.
- Zero-cost control, 1/3-session delay, terminal unremitted/transit identities;
  no spending unpaid dividends; whole/fractional constraints and unresolved
  corporate-action failure paths. Test conservation independently of returns.
- Metamorphic equivalence: give the shared THB schedule the dated amounts
  generated by the old USD mode; require identical remittances/contributions and
  terminal balances. Constant-FX zero-cost equivalent native inputs must agree.
- Existing [V36 funding tests](../../tests/unit/research/test_d6_v36_funding_attribution.py)
  and [V35 contribution tests](../../tests/unit/research/test_d6_v35_contributions.py)
  are regression starting points. Preserve all 80 recorded V36/V35 comparison
  cells when inputs are available; disclose missing inputs instead of fetching.
- Two offline runs must have identical canonical result digests, with exact
  input/config/runtime identity. Keep licensed data and raw outputs ignored.
- Run targeted tests, full prescribed hermetic tier once at integration, strict
  MyPy and exact-head PR CI. Inspect every warning and excluded tier. No full
  backtest or numerical reproduction is claimed by this planning document.
